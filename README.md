# Claude Overlay

Полупрозрачное окно поверх экрана. По сочетанию клавиш снимает скриншот, отправляет его в Claude API и показывает ответ. Параллельно может слушать системный звук звонка и локально расшифровывать его через Whisper — расшифровка последних двух минут уходит вместе со скриншотом. Окно не попадает в демонстрацию экрана и в системные скриншоты.

Форк [cheating-daddy](https://github.com/sohzm/cheating-daddy) (GPL-3.0). От оригинала осталась оболочка Electron — скрытое окно, глобальные хоткеи, click-through. Слой Gemini Live (стриминг аудио по WebSocket, Groq, локальные модели) вырезан целиком: у Claude API нет live-сокета, там обычный запрос-ответ с изображением.

## Установка

```bash
npm install
npm start
```

При первом запуске macOS попросит разрешение **Системные настройки → Конфиденциальность → Запись экрана**. Без него скриншоты будут пустыми.

Ключ Anthropic вводится во вкладке «Настройки». Он хранится в `~/Library/Application Support/claude-overlay/credentials.json` с правами `0600` и никогда не попадает в репозиторий, в логи и в текст ошибок.

## Хоткеи

| Сочетание | Действие |
| --- | --- |
| `Alt+Space` | Снять экран и спросить |
| `Alt+Shift+Space` | Ответ по речи за последние 20 секунд — в попапе |
| `Alt+\` | Спрятать / показать окно |
| `Alt+M` | Клики проходят сквозь окно |
| `Alt+L` | Слушать звук встречи (вкл/выкл) |
| `Alt+N` | Сбросить диалог и счётчик |
| `Alt+Shift+↑` / `↓` | Прокрутка ответа |
| `Alt` + стрелки | Двигать окно |
| `Alt+H` | Спрятать / показать подсказки |
| `Alt+Shift+E` | Стереть ответ и выйти |

**Почему всё на Alt.** Глобальная регистрация отбирает сочетание у всей системы. `Cmd+M` сворачивает окна везде, `Cmd+Enter` отправляет сообщения в мессенджерах — забрать их значит сломать их во всех приложениях сразу. macOS почти не занимает `Option+клавиша`, поэтому цена перехвата минимальна.

Любое сочетание переназначается во вкладке «Хоткеи»: нажми на текущее и введи новое. Сочетание, занятое другой программой, подсвечивается красным — раньше такая неудача проходила совершенно молча, потому что `globalShortcut.register` не бросает исключение, а возвращает `false`.

Клавиша определяется по физической позиции, а не по символу: на русской раскладке `Option+буква` даёт спецсимвол, и по нему сочетание собрать нельзя.

**Click-through выключен по умолчанию.** Пока он выключен, окно принимает клики обычным образом. После `Cmd+M` клики проходят насквозь в приложение под окном — кнопки в этот момент нажать нельзя, остаются только хоткеи. Чтобы это не выглядело зависанием, рамка окна становится жёлтой пунктирной, а в шапке появляется метка «сквозь · Cmd+M».

## Порядок работы

Приложение открывается на **экране подготовки** — окно с боковыми вкладками. Его проходят до встречи, не во время.

| Вкладка | Что внутри |
| --- | --- |
| **Сессия** | всё, что задают перед конкретной встречей: модель и глубина рассуждения, профиль, свой контекст, качество кадра, звук и распознавание |
| **Хоткеи** | все сочетания с переназначением, плюс настройка подсказок поверх экрана |
| **Настройки** | общее и разовое: ключ, свой адрес API, прокси, шрифт, непрозрачность, выбор монитора |
| **История** | прошлые сессии с итогами и кнопкой открыть каталог |

Разделение простое: во вкладке «Сессия» лежит то, что меняют от встречи к встрече, в «Настройках» — то, что задают один раз.

Кнопка **«Начать сессию»** закреплена внизу вкладки «Сессия» и не уезжает при прокрутке. По ней приложение проверяет захват экрана, поднимает звук, показывает подсказки и сжимается в компактное окно. Кнопка **⚙** в окне сессии возвращает назад.

**Окно тянется за угол.** Ниже 620 пикселей ширины боковые вкладки схлопываются в иконки, ниже 460 — парные поля перестраиваются в столбик.

**Окно не уезжает за край экрана.** Раньше стрелками его можно было увести за границу и потерять: заголовка не видно, вернуть нечем. Теперь позиция удерживается в рабочей области — и при перемещении, и при показе после того, как экран мог смениться.

**Переключатели вместо галочек, списки вместо радиокнопок.** Состояние переключателя читается издалека, а список из трёх строк не занимает три строки.

**Текст интерфейса говорит о следствии, а не об устройстве.** Подпись под переключателем объясняет, что изменится («без неё Claude отвечает только про то, что видит»), а не как это сделано. Ошибки построены как «что случилось — что делать»: «Ключ отклонён. Проверь его во вкладке „Настройки“», «Нет связи с API. Проверь интернет, ВПН или прокси». Термин один на всё приложение: везде «глубина рассуждения», нигде не «эффорт».

**Индикатор состояния** — кружок в левом верхнем углу, одинаковый на обоих экранах. Наведи, и он покажет четыре пункта: ключ, экран, звук, невидимость окна. Отдельно отслеживается разница между «в переговорке тишина» (норма) и «звук перестал поступать» (поломка): захват шлёт пульс независимо от того, есть ли речь.

## Подсказки поверх экрана

Во время сессии у края экрана висит полупрозрачная плашка с пятью главными сочетаниями. Место выбирается в «Хоткеях» — любой из четырёх углов, по умолчанию снизу справа, рядом с доком, где почти всегда пусто.

Плашка не принимает клики: они проходят насквозь в окно под ней. Скрывается и возвращается по `Alt+H`, и это состояние запоминается.

В неё вынесены только те сочетания, которые жмут на встрече. Полный список живёт во вкладке «Хоткеи» — поверх чужого окна он был бы шумом.

## Разметка ответа

Ответ рендерится как markdown: таблицы, списки, цитаты, подсветка кода. Формулы в `$…$` и `$$…$$` (а также `\\(…\\)` и `\\[…\\]`) отрисовываются через KaTeX — он завендорен локально в `src/assets/katex/` (592 КБ, только woff2), никаких обращений к CDN. Кривая формула не роняет весь ответ: показывается исходный текст.

Таблицы стилей подключаются **внутрь shadow root** компонента. Стили документа через границу shadow DOM не проходят — если вынести их в `index.html`, ни формулы, ни подсветка кода оформлены не будут.

## Окно сессии — чат

Окно сессии показывает всю переписку встречи, а не последний ответ: вопросы, ответы, миниатюры отправленных кадров. Раньше новый запрос затирал предыдущий, и вернуться было некуда. Вызывается и прячется по `Alt+\`.

Устройство повторяет привычный чат с ассистентом:

- **Колонка сообщений ограничена по ширине и центрирована.** Окно тянут широким, а строка в сто символов читается заметно хуже, чем в семьдесят.
- **Реплика пользователя — компактный блок справа**, ответ идёт во всю колонку без рамки. Кто говорит, видно по форме, а не по подписи.
- **Композер снизу собирает поле и управление в один блок.** Модель и глубину меняют перед отправкой, поэтому они здесь, а не в заголовке. Поле растёт под текст до трёх строк, `Enter` отправляет, `Shift+Enter` переносит строку.
- **Действия появляются у самого сообщения по наведению** — копировать и переспросить. Постоянные кнопки под каждым ответом шумят сильнее, чем помогают. Там же слева стоят модель и цена этого ответа.
- **Лента прилипает к низу, только если ты и так внизу.** Иначе дочитать старый ответ, пока снизу растёт новый, было бы невозможно. Когда прокрутка ушла вверх, появляется кнопка возврата.

**Миниатюра кадра** отвечает на вопрос «а тот ли экран он снял». Хранится уменьшенная копия шириной 220 пикселей, а не исходный кадр: полный base64 на каждый ход раздувал бы память.

**«Повторить»** переспрашивает тем же кадром и тем же вопросом. Пересъёмка стоит денег и ловит уже другой экран, а модель к этому моменту могли сменить в шапке — так что это же и способ переспросить у более сильной модели. Повтор помечается в ленте чипом.

**«Стоп»** прерывает ответ. Opus на высокой глубине думает долго, и если вопрос задан не тот, ждать незачем.

## Два окна

Сессия состоит из двух независимых окон.

**Основное** — работа по экрану: `Alt+Space` снимает экран и задаёт вопрос, ответ приходит сюда.

**Попап в углу** — работа по речи. Показывает живую расшифровку серым, поверх неё выводится ответ. Поднимается вместе с сессией, если включено прослушивание; прячется кнопкой или при возврате в подготовку.

У окон **разные диалоги**: разбор кода на экране не перемешивается с репликами совещания, и сбрасываются они по отдельности. У попапа своя модель и свой эффорт — на совещании ответ нужен за секунды, а Opus на `xhigh` будет думать полминуты.

По `Alt+Shift+Space` попап отвечает **только по последним 20 секундам**. Длинный контекст уводит модель к прошлой теме вместо того вопроса, который только что прозвучал. Срез по возрасту не разрушает буфер: десятиминутная память основного окна остаётся нетронутой.

Свою речь приложение не пишет — только то, что звучит из динамиков или наушников. Свой вопрос человек и сам сформулирует, а вот реплику собеседника быстро — нет.

## Экран и звук: два независимых запроса

- `Alt+Space` — вопрос по тому, что на экране. Если в поле внизу набран текст, он уходит вместе со скриншотом: «объясни этот запрос» и «реши эту задачу» — разные вопросы к одной картинке. Пустое поле означает вопрос по умолчанию.
- `Enter` в поле — вопрос без скриншота, по уже отправленному экрану.
- `Alt+Shift+Space` — вопрос по тому, что прозвучало, без скриншота.

Звук пишется непрерывно, пока включено прослушивание, но **сам по себе никогда ничего не отправляет** — только по хоткею. Пока идёт ответ по скриншоту, запись продолжается.

По `Alt+Shift+Space` недобранное окно принудительно сбрасывается в whisper, и запрос **ждёт** его расшифровки. Без этого последние ~13 секунд (окно 10 с плюс время распознавания) в запрос не попадали бы — то есть ровно тот вопрос, ради которого жмут хоткей. Обрывки короче полсекунды не отправляются: на них whisper выдумывает текст.

По умолчанию расшифровка **не** прикладывается к запросам по экрану: иначе модель начинает отвечать про разговор вместо того, что на экране. Включается галкой «Прикладывать расшифровку и к запросам по экрану».

**Память разговора — 10 минут** (настраивается: 2, 5, 10, 30). Двух минут не хватало: вопрос, который обсуждают до сих пор, мог прозвучать раньше и молча выпадал из буфера. Реальный предел объёма задаёт не время, а лимит в 6000 символов, и при переполнении выбрасываются целые реплики, начиная со старых, — обрубок фразы без начала модели бесполезен.

В запрос расшифровка уходит с пометками давности:

```
[3 мин назад] Давайте вернёмся к вопросу о сроках релиза.
[только что] А по бюджету что решили?
```

Без них реплика десятиминутной давности неотличима от прозвучавшей только что, и модель отвечает не на тот вопрос. Новая метка ставится после паузы длиннее 45 секунд.

### Стык окон

Звук режется окнами по 10 секунд, каждое следующее начинается на секунду раньше конца предыдущего. Без этого перехлёста слово на границе разорвалось бы пополам и было бы изуродовано в обоих окнах.

Плата за перехлёст — эта секунда распознаётся дважды, и на стыке текст дублируется. Поэтому у нового фрагмента срезается начало, совпадающее с концом предыдущего.

Совпадение ищется **с допуском**: одну и ту же секунду соседние окна распознают по-разному, потому что вокруг неё разный контекст, и чаще всего расходится окончание слова — «интеграцию» против «интеграции». Требование точного совпадения оставляло заикание почти на каждом стыке.

Допуск — расстояние Левенштейна: одна правка для слов до семи букв, две для длинных. Слова короче четырёх букв сравниваются только точно: на «он» и «от» допуск склеил бы несвязанные реплики. `ё` и `е` считаются одной буквой.

## Свой адрес API

Если ключ идёт не напрямую в Anthropic, а через шлюз с совместимым API (LiteLLM, корпоративный прокси, посреднический сервис), адрес задаётся во вкладке «Настройки». Пустое поле — обращение напрямую.

Это заодно решает вопрос доступности: запрос уходит на промежуточный сервер, а до Anthropic добирается уже он.

Разбор адреса строгий, потому что **по этому адресу уходит API-ключ**:

- только `https`; `http` разрешён исключительно для `localhost` и `127.0.0.1`, где трафик не покидает машину;
- учётные данные в адресе (`https://user:pass@…`) отклоняются;
- хвостовой `/v1` срезается — SDK дописывает `/v1/messages` сам, и адрес, скопированный вместе с `/v1`, дал бы путь с двумя `/v1` и невнятный 404.

Пока свой адрес задан, под полем висит предупреждение с этим адресом: ключ уходит туда, и доверие к этому серверу — твоё решение.

**AWS Bedrock и Google Vertex так не подключить.** У них другая авторизация (SigV4), другие идентификаторы моделей и отдельный SDK — это отдельная работа, а не смена адреса.

## Границы процесса

Страница, где рендерится вывод модели, работает **без Node**: `contextIsolation` включён, `nodeIntegration` выключен. В ней `require` и `process` — `undefined`, проверено. Раньше любой скрипт на странице имел полный доступ к файловой системе и процессам.

Мост живёт в `src/preload.js` и отдаёт наружу только `window.overlay` — заранее описанный набор вызовов. Захват звука тоже переехал туда: он трогает `getDisplayMedia` и `AudioWorklet`, но управляется через тот же мост.

`sandbox` оставлен выключенным: песочный preload не умеет подключать локальные модули, а мост состоит именно из них. Границу это не отменяет — Node недоступен там, где отображается недоверенный текст.

**Кадры не копятся в памяти.** В истории диалога изображение остаётся только у самого свежего хода: в запрос уходит один кадр, а держать остальные по двести килобайт в base64 всю встречу незачем. Текст всех ходов при этом сохраняется целиком.

## Прокси вместо системного ВПН

Если API недоступен напрямую, не обязательно поднимать ВПН на весь компьютер. Во вкладке «Настройки» включается прокси (socks5/socks4/http/https) — и через него пойдёт **только это приложение**.

Работает так: запросы к API выполняются через `net.fetch` Electron, то есть через сетевой стек Chromium, который уважает прокси сессии. Обычный `fetch` из Node прокси сессии игнорирует — поэтому клиенту SDK явно передаётся `fetch`.

Адрес прокси проверяется по белому списку символов: он подставляется в строку правил Chromium, и спецсимволы в нём — способ подменить адрес.

**Скачивание моделей whisper прокси не использует** — оно идёт напрямую через Node. Если HuggingFace тоже недоступен, модели придётся скачать при включённом ВПН.

## Модели и эффорт

Модель и глубину рассуждения (`effort`) можно менять на лету в шапке окна.

| Модель | Эффорт | Когда |
| --- | --- | --- |
| Opus 5 | low…max | Сложные задачи, код, разбор архитектуры |
| Sonnet 5 | low…max | По умолчанию: баланс скорости и качества |
| Haiku 4.5 | — | Когда нужен максимально быстрый и дешёвый ответ |

Haiku 4.5 не принимает `effort` — селектор для неё отключается, и при смене модели несовместимый уровень сбрасывается автоматически.

**Картинка в истории.** Скриншот сохраняется в истории только для последнего хода. Уточняющий вопрос («объясни подробнее») задают про тот же экран, и без картинки модель отвечала бы вслепую, по одному своему прошлому тексту. Но как только приходит новый скриншот, старый вырезается: он лишь дублирует свежий, а оплачивается наравне с ним.

Профиль (`Совещание` / `Собеседование` / `Свободный`) и поле «Свой контекст» подставляются в системный промпт. Системный промпт помечен `cache_control: ephemeral` — при серии запросов подряд он тарифицируется как чтение кеша.

## Звук и расшифровка

Снимается **системный звук** — то, что говорят собеседники. Свой микрофон не пишется. macOS отдаёт системный звук через тот же ScreenCaptureKit, что и картинку, поэтому отдельных драйверов вроде BlackHole не нужно; видеотрек гасится сразу после старта, остаётся только аудио.

Звук режется на окна по 10 секунд с секундой перехлёста, окна тише порога сразу отбрасываются (whisper склонен выдумывать текст на тишине). Расшифровка идёт локально через `whisper-cli`, аудио никуда не отправляется. Временный WAV удаляется сразу после распознавания в любом исходе.

Требуется whisper.cpp:

```bash
brew install whisper-cpp
```

Модели скачиваются один раз кнопкой в настройках и лежат в `~/Library/Application Support/claude-overlay/models/`. При скачивании проверяется SHA-256 по списку, зафиксированному в `src/utils/whisper-models.js`.

| Модель | Файл | RAM | Замер на M1 (окно 10 с) |
| --- | --- | --- | --- |
| Small | 181 МБ | ~600 МБ | 1,6–2,2 с |
| Large v3 Turbo | 547 МБ | ~1600 МБ | 3,2–3,6 с |

**Medium убран.** У turbo 809M параметров против 769M у medium — та же память, но качество уровня large и вчетверо меньше декодерных слоёв. Держать его в списке было незачем.

Модель загружается заново на каждое окно (~0,7 с из времени выше). Это плата за отказ от постоянного локального сервера whisper: лишний слушающий порт того не стоит.

## История сессий

Каждая сессия пишется в свой каталог `~/Library/Application Support/claude-overlay/sessions/<дата-время-суффикс>/`. Имя сортируется как время, поэтому каталоги выстраиваются по порядку сами.

```
2026-08-13-1807-fb5b/
├── session.json     метаданные и итоги
├── log.jsonl        ход сессии, по записи на строку
└── shots/0001.jpg   кадры ровно в том виде, в каком ушли в модель
```

`log.jsonl` устроен экономно: короткие ключи, время относительно начала сессии, кириллица не экранируется. Пять записей занимают меньше трёхсот байт.

```
{"t":6,"k":"start","m":"claude-sonnet-5","e":"medium","p":"meeting"}
{"t":318,"k":"ask","q":"что на экране","s":1}
{"t":318,"k":"ans","x":"Тут окно терминала.","i":1730,"o":42,"c":0.0081}
{"t":318,"k":"speech","x":"а что по срокам?"}
{"t":318,"k":"end"}
```

Кадры сохраняются тем же JPEG, что ушёл в модель: пересжатие сделало бы запись расходящейся с тем, что Claude на самом деле видел.

В `session.json` лежат итоги — число запросов, токены, потраченные доллары, число кадров и ошибок, длительность, а также модель, эффорт и профиль, с которыми шла работа. Последние пять сессий видны во вкладке «История», кнопка «Открыть» показывает каталог в Finder.

**Каталоги не подчищаются сами.** Кадры встреч копятся, и это твои данные — удалять их за тебя приложение не станет.

## Стоимость

В шапке окна сессии показан **счётчик потраченного** — он считает по `usage` из ответов API, а не по оценке. Обнуляется по `Alt+N`.

Из чего складывается один запрос: скриншот 1440×900 ≈ 1730 токенов (формула `ширина × высота / 750`), системный промпт ~450 токенов, но он под `cache_control` и со второго запроса стоит 0,1×, история диалога до ~4000 токенов, расшифровка звука ~700 токенов за две минуты речи.

**Выход дороже входа впятеро**, и на сложных задачах он почти весь уходит в мышление. Поэтому счёт определяет `effort`, а не качество скриншота: сам скриншот на Sonnet стоит около $0,003.

Оценка на сессию из ~20 запросов (30 минут работы):

| Модель | За запрос | За сессию |
| --- | --- | --- |
| Haiku 4.5 | ~$0,006 | ~$0,12 |
| Sonnet 5, medium | ~$0,022 | ~$0,45 |
| Opus 5, medium | ~$0,05 | ~$1,0 |
| Opus 5, xhigh | ~$0,09–0,15 | ~$2–3 |

Цены за миллион токенов зашиты в `src/utils/pricing.js`. У Sonnet 5 там же прописана вводная цена $2/$10 с датой окончания — после 31 августа 2026 счётчик сам перейдёт на обычные $3/$15.

## Тесты

```bash
npm test
```

Тестами покрыто ядро: сборка запроса к API и уровни эффорта (`claude-client.js`), кодирование WAV и детектор тишины (`audio-buffer.js`), нарезка окон с перехлёстом (`audio-chunker.js`), скользящий буфер расшифровки со склейкой дублей на стыках (`transcript.js`), реестр моделей whisper (`whisper-models.js`), правила индикатора состояния (`health.js`), расчёт стоимости (`pricing.js`), разбор настроек прокси (`proxy.js`), сочетания клавиш и их разбор из события (`keybinds.js`), поколения запросов (`request-gate.js`), имена временных файлов (`temp-files.js`), схлопывание частых записей (`debounce.js`).

Окно, хоткеи, захват экрана и UI тестами не покрыты — проверяются руками:

1. `npm start` — открывается экран подготовки, индикатор красный, «Начать сессию» заблокирована.
2. Ввести ключ, «Сохранить», «Проверить» — должно появиться «Ключ работает, ответила …», индикатор позеленеть.
3. «Начать сессию» → окно сжимается, снизу появляются серые подсказки, а при включённом звуке — полоса расшифровки.
4. `Cmd+Enter` поверх любого приложения — кружок пульсирует, ответ приходит потоком.
5. Сделать системный скриншот (`Cmd+Shift+4`) — окна на нём быть не должно.
6. `Cmd+M` — рамка становится жёлтой пунктирной, в шапке появляется «сквозь», клики уходят в приложение под окном. Повторный `Cmd+M` возвращает всё обратно.
7. Переключить модель на Haiku 4.5 — селектор эффорта гаснет.
8. Во время звонка навести на кружок — все четыре пункта должны быть зелёными.
9. После пары запросов в шапке должна расти сумма; `Cmd+Shift+N` обнуляет её.
10. Ответ с формулой — проверить, что она отрисована, а не показана как `\frac{a}{b}`.
11. `Alt+Shift+Space` при пустой расшифровке — сообщение «нечего разбирать», запрос не уходит.
12. Нажать `Alt+Space` дважды подряд — второй ответ должен прийти без красной ошибки от первого.
13. Переназначить сочетание на экране подготовки, нажать «Вернуть умолчания» — должно вернуться исходное.
14. Во время прослушивания переключить вывод на наушники — в полосе появится «восстанавливаю», затем звук должен пойти снова.
15. Усыпить и разбудить ноутбук — приложение вернётся на экран подготовки с сообщением про сон.

## Поведение в нештатных ситуациях

**Обрыв захвата звука.** Поток рвётся сам при смене устройства вывода (наушники) или засыпании машины. Захват перезапускается автоматически: три попытки с задержкой 1, 2 и 4 секунды, с сообщением в полосе расшифровки. Закрепить конкретное устройство нельзя — loopback снимает системный микс целиком, он выше устройства вывода, и выбора там нет.

**Сон компьютера.** После пробуждения приложение закрывает сессию и возвращает на экран подготовки с сообщением. Права и потоки после сна ведут себя непредсказуемо, поэтому честнее начать заново, чем делать вид, что всё работает.

**Паника (`Alt+Shift+E`).** Перед выходом синхронно убивается процесс whisper и стираются все временные файлы — обычный `finally` не успевает отработать, если процесс убивают во время расшифровки. Осиротевшие от прошлых аварий файлы подчищаются при следующем запуске: признак узкий (наш префикс плюс шестнадцатеричный хвост), чужое в общем каталоге не трогается.

**Приложение не выходит само.** Необработанные исключения и отказы промисов логируются, но не роняют процесс. Закрытие окна прячет его, а не завершает работу.

**Два монитора.** Снимается основной. Следование за курсором регулярно снимало не тот экран, на который человек смотрит, поэтому по умолчанию выключено; если мониторов больше одного, в настройках появляется галка вернуть прежнее поведение.

## Ограничения

- Пишется только системный звук. Свой микрофон не захватывается: если нужен и он, это отдельная доработка.
- История диалога и расшифровка живут в памяти процесса: перезапуск или `Alt+N` их стирают. Скриншоты в историю не переносятся — только текст.
- На 8 ГБ RAM turbo вместе с браузером на звонке заметно нагружает память. Если начнётся своп, переключись на small.
- Запись разговора в ряде юрисдикций требует согласия собеседников — это на твоей стороне.
